# Sistem Panen

# Deskripsi

Sistem Panen adalah program Python sederhana untuk menghitung total hasil panen berdasarkan jumlah hasil panen dan harga per kilogram. Program ini juga dilengkapi dengan fitur perhitungan diskon.

# Cara Menjalankan Program

1. Pastikan Python sudah terpasang pada komputer.
2. Clone repository ke komputer dengan perintah:

   ```bash
   git clone https://github.com/USERNAME/sistem-panen-meilia.git
   ```
3. Masuk ke folder proyek:

   ```bash
   cd sistem-panen-meilia
   ```
4. Jalankan program:

   ```bash
   python program.py
   ```

Program akan menampilkan total hasil panen, jumlah diskon, dan total setelah diskon.
